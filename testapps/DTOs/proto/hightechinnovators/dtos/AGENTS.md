# testapps/DTOs/proto/hightechinnovators/dtos

Package `hightechinnovators.dtos`: one folder per DTO plus the shared `type` package. Conventions: [../../AGENTS.md](../../AGENTS.md).

## Folders

- `demodto/` — `Demodto` contract, the DTO every host serves. See [demodto/AGENTS.md](demodto/AGENTS.md).
- `testdto/` — `Testdto` contract, same entity shape with a smaller writer API. See [testdto/AGENTS.md](testdto/AGENTS.md).
- `type/` — request/response messages shared by all DTO services. See [type/AGENTS.md](type/AGENTS.md).
